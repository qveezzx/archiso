Quick start

Up and running
in three steps.

No wiki spelunking needed. Download, flash, and install — the graphical installer handles the rest.

01 /
Download the ISO
Grab the latest image from GitHub Releases. Verified SHA256 checksums included.
02 /
Flash to USB
Use dd, Ventoy, or Balena Etcher. Any 2 GB+ drive works.
03 /
Install with Calamares
Boot into the live environment, launch the installer from the desktop, and follow the prompts.
bash — 80×24
# — verify the image
$ sha256sum zuccos-latest.iso
a4f3bc7d...  zuccos-latest.iso
# — flash to /dev/sdX (replace X)
$ sudo dd if=zuccos-latest.iso \
of=/dev/sdX bs=4M status=progress
# — after install: update the system
$ sudo pacman -Syu
:: Synchronising package databases...
:: Starting full system upgrade...
there is nothing to do

Prefer a GUI? Ventoy and Balena Etcher work just as well.
The live session is fully usable before installing.

Heads up before you download

ZuccOS follows a rolling release model — builds are pushed directly from the repository and are not pre-tested before they go live. What you're about to download is the latest available snapshot, not a stable, QA'd release.

  • Check the Issues tab for known problems with the current build.
  • Read recent commits on GitHub to see what changed.
  • Always verify the SHA256 checksum after downloading.

If you hit a broken build, opening an issue is genuinely appreciated.
